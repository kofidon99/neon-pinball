# Neon Pinball

Light up the bumpers. Keep the ball alive.

Pinball arcade game. Tap either side to flip. Tap LAUNCH to serve. Two thumbs or one finger.

## Hosting

Serve this folder with any static HTTP server. Enable Settings → Pages → GitHub Actions. The included workflow publishes the standalone game.

Expected URL after deployment: https://kofidon99.github.io/neon-pinball/

## YouTube

Upload the contents of youtube/ as a separate Playables bundle, with index.html at its root. This is a pitch build, not a certified release. SDK testing, real Android/iOS checks, metadata and platform review are still required. No third-party game assets or licensed team/vehicle branding are included.
